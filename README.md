# 🛍️ Customer Shopping Behavior Analysis

An end-to-end data analytics project analyzing customer shopping behavior using **Python, PostgreSQL, SQL, and Power BI**.

The project focuses on understanding customer spending patterns, product preferences, discount behavior, customer segments, and subscription trends to generate actionable business insights.

---

## 📌 Project Overview

This project analyzes **3,900 customer purchase transactions** across various product categories.

The main objective is to transform raw transactional data into meaningful business insights through:

- Data Cleaning
- Exploratory Data Analysis
- Feature Engineering
- SQL Business Analysis
- Customer Segmentation
- Power BI Dashboard Development
- Business Recommendations

### 🎯 Key Objectives

- Understand customer spending patterns
- Identify top-performing products
- Analyze subscription behavior
- Evaluate discount usage
- Segment customers based on purchasing behavior
- Identify high-revenue customer groups
- Generate data-driven business recommendations

# 🔍 Exploratory Data Analysis

Python and Pandas were used for data cleaning, exploration, and feature engineering.

### Data Preparation

The following steps were performed:

1. Loaded the dataset using Pandas.
2. Inspected the dataset using `df.info()`.
3. Generated statistical summaries using `df.describe()`.
4. Checked missing values.
5. Imputed missing `Review Rating` values using the median rating of each product category.
6. Standardized column names using `snake_case`.
7. Created an `age_group` feature based on customer age.
8. Created a `purchase_frequency_days` feature.
9. Checked whether `discount_applied` and `promo_code_used` contained redundant information.
10. Removed the redundant `promo_code_used` column.
11. Loaded the cleaned dataset into PostgreSQL.

🗄️ PostgreSQL & SQL Analysis

The cleaned dataset was imported into PostgreSQL for structured business analysis.

The following business questions were answered using SQL:

1. Revenue by Gender

Compared total revenue generated by male and female customers.

2. High-Spending Discount Users

Identified customers who used discounts but still spent above the average purchase amount.

3. Top 5 Products by Rating

Identified products with the highest average review ratings.

4. Shipping Type Comparison

Compared average purchase amounts between Standard and Express shipping.

5. Subscribers vs Non-Subscribers

Compared:

Total Customers
Average Spending
Total Revenue

across subscription status.

6. Discount-Dependent Products

Identified products with the highest percentage of discounted purchases.

7. Customer Segmentation

Customers were classified into:

New
Returning
Loyal

based on their previous purchase history.

8. Top 3 Products per Category

Identified the three most purchased products within each category using SQL window functions.

9. Repeat Buyers & Subscriptions

Analyzed customers with more than five previous purchases and compared their subscription status.

10. Revenue by Age Group

Calculated total revenue generated by different customer age groups.
